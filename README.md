## How to install

To install and run BPM you will need :

* Debian / Fedora based linux distribution
* Bash
* curl
* git (optional)

## How to run

First clone the repository or download it from the release section cd in the BPM folder and run "bash main.sh"

## Good to know

BPM is primaly a "from source" package manager that means that BPM won't download a precompiled binary but will rather download the source code of an applications and then compile it on your machine. 
You won't need to install a compiler (you can if you want to) because BPM as the "id" command that will install all the compiler you need for your distribution.
